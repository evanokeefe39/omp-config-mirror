# /imp-standardize — write standard work

Invoke the `imp-standardize` skill to turn a process you have **actually done**
into standard work: a workflow document a human can follow, capped at five steps,
one verification step, a named exit condition, shipped as an invocable skill and
indexed in `WORKFLOWS.md`.

Run the skill now. Read `skill://imp-standardize` first. Do not standardise what
you have not done — bring dated instances, or the honest answer is "not yet".
