# /imp-setup — establish a scope's operating model

Invoke the `imp-setup` skill: a **plan/apply** pass over the scope you name.
Survey the ground, classify it greenfield or brownfield, declare the lifecycle
stages, then propose — the four ledgers, and for a brownfield scope exactly what
you would seed into each, with the artifact that justifies every row. Write
nothing until that plan is approved.

Scope is any artifact-producing system, not only a codebase: a repository, the
global harness, a document set, a content channel, a media library.

Run the skill now. Read `skill://imp-setup` first — it carries the survey, the
seeding table and the scaffolder. Row formats belong to `imp-defect`,
`imp-feedback` and `imp-change`.
