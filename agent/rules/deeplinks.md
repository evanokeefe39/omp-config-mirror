# Deep-link every artifact you deliver

Whenever you create, modify, generate, or land something the user may want to
open or reuse — a new file, a written doc/report/postmortem, a web page/HTML,
an asset or code change, a UI, a rendered chart/figure, a screenshot, or any
other deliverable with a path or URL — ALWAYS include a clickable deep link to
it in the same message where you present it. Do not wait to be asked.

- Local files/docs: a `file:///` URL to the exact path (e.g.
  `file:///C:/Users/<user>/repos/<repo>/docs/example.md`), plus the repo-relative
  path in prose.
- Web/remote assets or apps: the live URL.
- Where several artifacts are produced, list each with its own link.

Give the link up front or inline with the first mention of the artifact. A bare
path alone is not enough — the user must be able to click straight to it.
This applies to subagents too: when a delegated agent produces a file, surface
its link in your own reply.
