# writing-voice-samples

Reference samples of real voices: `~/repos/voice-samples`.

Writing or humanizing prose in someone's voice? Read
`~/repos/voice-samples/INDEX.md`, pick one voice by register, then read that
voice's `STYLE.md` and at least one sample before you draft. One voice per
piece; never blend two. The samples are verbatim, typos included, for analysis
only. Where a card and its samples disagree, the samples win.

The repo's `README.md` carries the rest: how to add a voice, and the provenance
and permission rules for other people's writing.

Human-invoked: this rule has no agent binding by design. It triggers on a
person asking for prose in a specific voice, which no agent definition can
anticipate and no condition can match — the trigger is the request itself.
